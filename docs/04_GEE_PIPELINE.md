# 04 — Пайплайн Earth Engine

## Запуск

```bash
cd pipeline && pip install -r requirements.txt && cd ..
earthengine authenticate   # один раз
python3 -m pipeline.gee.run_real_pipeline \
    --years 2000-2026 --out data/real --project <ваш-gcp-project-id>
```

Опорный год для проверки направления трансект задаётся `--reference-year`
(по умолчанию 2026 — обычно лучшее покрытие Sentinel-2).

## Модули

| Файл | Роль |
|---|---|
| `gee/config.py` | AOI, CRS, годы, `COAST_WAYPOINTS`, веса риска |
| `gee/bands.py` | Схемы каналов и коэффициенты масштабирования по коллекциям |
| `gee/indices.py` | MNDWI, облачные маски (QA_PIXEL для Landsat, SCL для Sentinel-2) |
| `gee/composite.py` | Медианный июльский композит; расширение окна до июнь–август при нехватке сцен |
| `gee/otsu.py` | Порог Оцу по гистограмме, посчитанной на сервере GEE |
| `gee/geometry.py` | Прибрежный коридор — буфер вокруг `COAST_WAYPOINTS`, ограничивает область тяжёлых вычислений |
| `gee/sample_transects.py` | Сэмплинг MNDWI вдоль трансект-линий через `reduceRegions`, поиск перехода суша/вода |
| `gee/run_real_pipeline.py` | Оркестратор: baseline → направление трансект → по годам → регрессия → объекты |
| `transects/baseline.py` | Опорная линия из `COAST_WAYPOINTS`, смещённая в сушу на `BASELINE_OFFSET_M` |
| `transects/generate.py` | Перпендикулярные трансекты с заданным шагом |
| `transects/displacement.py` | Регрессия по позициям трансекты → скорость, доверительный интервал, класс уверенности |
| `risk/engine.py`, `forecast/scenarios.py` | Общие формулы риска/прогноза — используются и реальным пайплайном, и мок-генератором |
| `postprocess/critical_level.py` | Модуль 1 (после часа 36) |

## Известные проблемы данных и что с ними делать

- **Сцена не найдена для года** → окно автоматически расширяется до
  июнь–август; если и это не помогает, год помечается отсутствующим
  (как 2012 — Landsat 5 закрыт, Landsat 8 ещё не запущен).
- **Скорость выходит за диапазон 0–60 м/год** → почти наверняка не тот
  знак трансекты или баг в проекции; `pick_direction()` ловит первое
  автоматически, эмпирически проверяя обе стороны нормали на реальных
  пикселях.
- **Полигональная векторизация всей береговой линии не подходит** — см.
  подробный разбор в `00_DECISIONS.md`. Используется прямой сэмплинг
  трансект, не полигон.
- **`sampleRegions` с тысячами отдельных точечных Feature — медленно**
  (десятки тысяч геометрий в одном запросе). `reduceRegions` по геометриям
  линий — на два порядка быстрее (539 трансект — секунды, не минуты).
