# 07 — Frontend

Vite + React (JavaScript, без TypeScript). Состояние — zustand
(`src/store/useAppStore.js`), один источник правды для года, языка,
выбранного объекта и видимости слоёв.

## Экраны/блоки

- **Карта** (`src/map/MapView.jsx`) — Leaflet напрямую (не `react-leaflet`),
  `preferCanvas: true`. Слои: линия берега текущего года, трансекты
  (цвет — `risk_class`), объекты (цвет — категория), пылевые зоны и
  осушенное дно (по чекбоксам). Каждый слой явно снимается перед
  добавлением нового — без этого Leaflet копит слои в DOM при каждой
  смене года.
- **Тайм-слайдер** (`src/map/TimeSlider.jsx`) — год 2000–2026,
  автовоспроизведение с интервалом 700 мс. `stop()` вызывается в
  `onChange` до установки года вручную — иначе таймер автоплея на
  следующем тике перезаписывает выбор пользователя.
- **KPI-плитки** (`src/cards/KpiPanel.jsx`) — средняя скорость,
  число сегментов, площадь осушенного дна, число объектов высокого риска.
- **Панель объектов** (`src/cards/ObjectPanel.jsx`) — список по убыванию
  риска + детальная карточка (расстояние, скорость, прогноз, рекомендация).
- **Форма заявок** (`src/report/ReportForm.jsx`) — категория, описание
  10–1000 символов, необязательный контакт.
- **Экспорт PDF** (`src/pdf/exportPdf.js`) — html2canvas снимает DOM,
  jsPDF кладёт картинку на A4. Модуль грузится динамическим `import()`
  по клику — не раздувает основной бандл.

## Данные

При старте — один запрос `GET /bootstrap`. Если backend недоступен,
фронтенд переключается на `public/fallback/bootstrap.json`
(`src/api/client.js`) — офлайн-демо без сети.

## i18n

`src/i18n/translations.js` — плоские словари `ru`/`kk`/`en`, функция
`t(lang, key)` с фоллбэком на русский.
