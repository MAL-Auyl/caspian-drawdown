## Три независимых слоя, три зоны ответственности

`pipeline/` (геообработка) → `backend/` (расчёты риска/прогноза, раздача
данных) → `frontend/` (карта, взаимодействие). Каждый слой можно
разрабатывать и тестировать независимо на мок-данных правильной схемы
(`pipeline/mock/generate.py`) — это разблокирует фронтенд и бэкенд, не
дожидаясь готовности реального пайплайна.

## Извлечение позиции берега (ключевой алгоритм)

```
1. baseline = смещённая внутрь суши линия по COAST_WAYPOINTS
2. трансекты = перпендикуляры к baseline, шаг 500 м, длина 15 км
3. направление трансект проверяется эмпирически на одном опорном году
   (обе стороны нормали пробуются на реальных пикселях MNDWI)
4. для каждого года:
   a. композит Sentinel-2/Landsat за июль (окно расширяется при нехватке сцен)
   b. MNDWI + порог Оцу по прибрежному коридору
   c. reduceRegions по геометриям трансект-линий (не точки!) —
      один batch-запрос вместо тысяч сетевых обращений
   d. для каждой трансекты: сортировка пикселей по проекции на линию,
      поиск перехода суша→вода по порогу, линейная интерполяция
5. позиции по трансекте за все годы → линейная регрессия → скорость,
   доверительный интервал, класс уверенности
6. линия берега года для карты = точки пересечения всех трансект,
   соединённые по порядку — отдельного шага векторизации не нужно
```

Первая версия векторизовала береговую линию как единый полигон — это не
сработало на реальных данных (см. `00_DECISIONS.md`, раздел про смену
подхода). Текущая версия измеряет то, что реально нужно для DSAS, без
хрупкой промежуточной геометрии.

## Компонентная схема backend

`app/services/store.py` (загрузка в память) → `app/api/v1/routes_*.py`
(фильтрация и выдача) → `app/services/reports_db.py` (единственная
запись — SQLite для заявок). Подробности — `05_API.md`, `06_DATABASE.md`.

## Компонентная схема frontend

`store/useAppStore.js` (zustand, единый источник состояния) →
`map/MapView.jsx` (прямой Leaflet, без `react-leaflet`) →
`map/TimeSlider.jsx`, `cards/*`, `report/ReportForm.jsx`,
`pdf/exportPdf.js` (снимок DOM). Подробности — `07_FRONTEND.md`.
